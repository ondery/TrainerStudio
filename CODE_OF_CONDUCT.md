# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1.

Be respectful in issues, reviews, and discussions. Harassment, personal attacks, and publishing private information are not accepted.

Report conduct issues to the maintainers of the public repository when that contact address is published. Until then, use the private channel you already use with the maintainer. Reports are reviewed and, when needed, result in a warning, a temporary ban, or a permanent ban from the project spaces.
